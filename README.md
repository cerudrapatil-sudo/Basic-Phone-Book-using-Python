# Contact Management System:-

A simple console-based contact book application built in Python. Manage your contacts with add, remove, search, and display functionalities.

# Features :-

- **Add Contacts**: Validate and store name & 10-digit phone numbers
- **Remove Contacts**: Delete by name (case-insensitive)
- **Search Contacts**: Find phone number by name
- **Display All**: View complete contact directory
- **Duplicate Prevention**: Blocks duplicate names or phone numbers
- **Interactive Menu**: User-friendly console interface
